# 타입 병합 충돌

타입 합성에서 같은 이름의 파라미터가 있는 경우 타입은 둘을 모두 수용하는 방향으로 추론된다.

ex>
```typescript
type Props = {
  size: 'md' | 'lg';
} & {
  size: number;
}
```

위와 같은 경우 `size`의 `type`은 `string`으로 추론된다

실제 예시
```tsx
type Size = 'md' | 'lg';
const sizeVar = {
  'md': {},
  'lg': {},
}
type Props = {
  size: Size;
} & React.InputHTMLAttributes<HTMLInputElement> // size: number 존재

const Comp = ({size}: Props) => {
  const value = sizeVar[size]; // size가 string으로 변환 추론되었으므로 타입 에러 발생
} 

/** 아래와 같이 size를 제거  */

type Props = {
  size: 'md' | 'lg';
} & Omit<React.InputHTMLAttributes<HTMLInputElement>, 'size'>
```
